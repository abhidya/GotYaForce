identity, MATCH, runtime completion, live scheduling or playability. This reader
adds exactly **three fixed cell reads, 16 bytes total**, after the unchanged
whole-snapshot/schema/data5 authenticator. No initializer or other code body is
reread. No later launch/model row cell, pointer referent, target object, table,

Tests: `../tools/matching-decomp/test_archived_projectile_flight_prefix_evidence.py`.

## Reused instruction order and the honest boundary

All source addresses and object offsets here are hexadecimal. Saved owner r31
was loaded from canonical child90 at7ddb4. After successful HIT setup and the
joint-vector transform/optional vector addition, the existing full-body evidence
gives this exact order:

1. `7de58 lha r4,72(r31)` reloads the **fresh signed heading** from the saved
   owner. It does not reuse the earlier copied child72 or reload child90.
2. `7de5c addis r3,0,4330` forms the conversion high word.
   `7de60 lwz r0,c8(r31)` then reads the saved owner's actual target pointer.
   That load precedes all three constant loads and the angle calculation.
3. `7de64 xoris r4,r4,8000` flips bit31 of the sign-extended heading;
   `7de68 stw r3,c8(r1)` writes the stack double's high word.
4. `7de6c lfd f1,-28744(r2)` loads DOUBLE804379d8.
   `7de70 cmpli r0,0` compares the already-read target pointer.
   `7de74 stw r4,cc(r1)` supplies the conversion low word.
5. `7de78 lfs f2,-28788(r2)` loads FLOAT804379ac;
   `7de7c lfd f0,c8(r1)` loads the assembled double;
   `7de80 lfs f31,-28792(r2)` loads FLOAT804379a8 as positive-zero pitch.
6. `7de84 fsubs f0,f0,f1` performs single-precision subtraction;
   `7de88 fmuls f30,f2,f0` performs single-precision multiplication. Do not
   collapse these into an unrounded decompiler expression. The conversion
   subtraction is exactly the original signed short throughout−32768..32767.
   FPSCR and live floating-point mode are not newly authenticated here.
7. `7de8c` branches on the target-pointer comparison. A **genuinely null**
   pointer branches to7e024. A non-null pointer instead reaches target-vector
   subtraction8020ba78 at7de9c and subsequent ballistic math. Missing pointer
   storage does not establish null, and the pointer is never followed here.
8. On the actual-null branch, `7e024 fneg f1,f31` turns the authenticated
   positive-zero pitch into **negative zero**. `7e028/7e02c` pass stack94 and
   axis78, then `7e030` calls actual8020b238. The later yaw call is7e040.
   A short-angle/+0-only helper does not establish this general-radian/-0 call.

This evidence permits the caller to preserve genuinely completed earlier
mutations, acquire the fresh heading and target identity in source order, and
perform supported exact conversion before an explicit continuation boundary.
It does not manufacture a null target, supply generic trigonometry, establish
normalization/frsqrte or authorize later launch/model row defaults. No speed,
gravity, lifetime or model field is read by this reader.

'test_archived_projectile_flight_prefix_evidence.py' -v` passes **15 tests**.

  bytes, typed IEEE bits and payload hashes. Positive-zero/-zero are distinct.

  of the positive-zero cell. Truncation and appended bytes refuse.

  No initializer body is reread to perform this check.

  not runtime/original execution or a trigonometric backend.
- Exact three-read traces and physical spans are checked for both snapshots.
  Traces equal unchanged authentication reads plus the three literal cell reads.
  Every read is data5; no code or row read occurs.
- Wrong mappings, address/width types, duplicate cells, altered IEEE type/bits,

  Authentication and mapping refusal precede the selections.
- The CLI exposes no arbitrary-address/width, pointer, target or dump options.
  No external fetch/install, prior-authenticator edit, raw binary output,
  original execution, estimator import, commit or push is performed.
