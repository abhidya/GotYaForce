# Acceleration Ninja source child bridge

The original `0x80099e70` calls allocate child objects using the `0x802f3dd8` 60-byte variant table. Acceleration Ninja's source callback and dash emit rows 0x21–0x24. The playable Battle adapter now routes these rows to the existing `spawnRomProjectile` variant implementation instead of treating each row byte as a HIT kind or suppressing it. That implementation uses the decoded row's speed, drop, scale, lifetime, angle and kind; a real Battle B-input test checks that the successful allocation creates two children.

This is deliberately a partial gameplay connection, not original child parity. The existing variant spawner uses a generic muzzle instead of the original animated bone matrix, approximates aiming/collision/damage, and uses generic presentation. The actual original child creation, behavior, visual model and full attack outcome have not been compared against Dolphin or hardware. Unsuccessful ammo allocation still produces no children. Rows outside this exact actor/address/range are unchanged.
