## Exact supported prefix

1. Capture the first actor pointer. For each of six contiguous records, load
   raw active0 and test signed nonzero. Active records clear `58a`, `58b`, `58c`,
   `58d`, canonical action `7d2`, then actual `7d3`, in that order. There is no
   lifecycle or target-pointer read before these stores. A missing action owner
   or `7d2` destination therefore retains the first four clears.
2. Reload the first actor pointer. Only active records load signed lifecycle18.
   Raw `01..7f` reaches mandatory `6b450`; `00` and `80..ff` skip that call.
   The implementation refuses there instead of assuming `6b450` or subsequent
   `6b7f4` has no effect.
3. If all second-pass actors skip, reload the first actor pointer again. Each
   record first loads and captures active0, then loads canonical pointer508,
   **then** tests captured active0. A later active-byte change cannot replace
   that saved value. Inactive or explicit-null pointers skip; active nonnull
   pointers stop before **`8006b374`, target+83 ownership**. No missing binding
   is defaulted to null. The source does not load lifecycle18 in this pass.
