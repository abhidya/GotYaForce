# Contributor guide

Every accepted change should connect an input, a reproducible command, a
checked result, and the product behavior it supports.

## Choose a workflow

| Goal | Start here | Completion evidence |
| --- | --- | --- |
| Run the project | [Clean setup](./setup) | Locked install and production build pass |
| Change game code | [Verification](./verification) | Focused test plus workspace gates pass |
| Import recovered behavior | [Verified ports](./porting) | Schema, compile, oracle, and integration evidence |
| Rebuild assets | [Asset workflows](./assets) | Lawful inputs and output manifest/hashes |
| Diagnose a clean clone | [Troubleshooting](./troubleshooting) | Cause and recovery command recorded |

The root [`CONTRIBUTING.md`](https://github.com/abhidya/GotYaForce/blob/main/CONTRIBUTING.md)
defines repository-wide evidence, legal, and commit expectations.
